# Nwoke’m website

Premium gift boxes for men. Plain HTML/CSS/JS with no build step, ready for GitHub Pages.

## Pages
- `index.html` (home), `boxes.html`, `corporate.html`, `story.html`, `help.html`, `404.html`
- `coming-soon.html`: standalone pre-launch page. Not linked from the menu.

## Edit settings (one file)
Open `js/config.js` to set the WhatsApp number, Instagram/TikTok, email, box prices, delivery note and Bespoke lead time. Changes apply across every page.

## Before launch
- Set the WhatsApp number and prices in `js/config.js`
- Replace the jacket size chart in `help.html` with the supplier’s real measurements
- Add product photos when the sample boxes are shot (the box illustrations are placeholders)
- Domain: nwokem.co (set in the `CNAME` file). Buy it before switching on GitHub Pages.

## Show the pre-launch page as the home page
Rename `index.html` to `home.html`, then rename `coming-soon.html` to `index.html`. Reverse it on launch day.
